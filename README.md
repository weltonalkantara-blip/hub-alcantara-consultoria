# hub-alcantara-consultoria
Este repositório concentra o desenvolvimento do **Portal de Projetos da Alcântara Consultoria Farma 360**, criado para organizar e centralizar todos os projetos em um único acesso.   O sistema foi pensado para o **varejo farmacêutico**, com foco em clientes que utilizam o ERP **Alpha 7** e que buscam gestão eficiente e estratégica.
